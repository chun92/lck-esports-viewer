# LCK Esports Viewer

League of Legends LCK 리그의 선수/팀 정보를 보여주는 웹 앱.
JavaScript/Python 재활 훈련 프로젝트.

## 아키텍처

```
┌─────────────────────────────────────────────────────────────┐
│                        브라우저                               │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │ index.html  │  │  style.css  │  │       app.js        │  │
│  │  (마크업)   │  │  (스타일)   │  │  - fetch() 호출     │  │
│  └─────────────┘  └─────────────┘  │  - DOM 렌더링       │  │
│                                    │  - 검색/필터 이벤트 │  │
│                                    └─────────────────────┘  │
└──────────────────────────────┬──────────────────────────────┘
                               │ HTTP GET /api/...
┌──────────────────────────────▼──────────────────────────────┐
│                    Node.js / Express                         │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ index.js  (서버 진입점, 미들웨어 등록)               │   │
│  └──────────────────────────────────────────────────────┘   │
│  ┌──────────────────┐   ┌──────────────────────────────┐    │
│  │ routes/          │   │ routes/                      │    │
│  │   players.js     │   │   teams.js                   │    │
│  │  GET /players    │   │  GET /teams                  │    │
│  │  GET /players/:id│   │  GET /teams/:id/roster       │    │
│  └──────────────────┘   └──────────────────────────────┘    │
└──────────────────────────────┬──────────────────────────────┘
                               │ fs.readFile()
┌──────────────────────────────▼──────────────────────────────┐
│                        data/                                 │
│              players.json  /  teams.json                     │
└──────────────────────────────┬──────────────────────────────┘
                               │ json.dump()
┌──────────────────────────────▼──────────────────────────────┐
│                    Python 파이프라인                          │
│  ┌──────────────────────────────────────────────────────┐   │

│  └──────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ transform.py  — 정제/변환, players.json 저장         │   │
│  └──────────────────────────────────────────────────────┘   │

                               │ HTTP (requests)
                  ┌────────────▼────────────┐
                  │    Leaguepedia API       │
                  │  (Fandom MediaWiki API)  │
                  └─────────────────────────┘
```

## 프로젝트 구조

```
practice/
├── data-pipeline/        # Python — 데이터 수집 & 가공
│   ├── fetch.py
│   ├── transform.py
│   └── requirements.txt
├── api-server/           # Node.js — REST API
│   ├── src/
│   │   ├── routes/
│   │   └── index.js
│   └── package.json
├── frontend/             # Vanilla JS — 프론트엔드
│   ├── index.html
│   ├── style.css
│   └── app.js
└── data/                 # 공유 데이터 (Python 생성 → Node.js 읽기)
    └── players.json
```

## 기술 스택

| 레이어 | 기술 |
|--------|------|
| 데이터 수집/가공 | Python 3.11+ |
| API 서버 | Node.js 20+ / Express |
| 프론트엔드 | Vanilla HTML/CSS/JavaScript |
| 데이터 저장 | JSON 파일 → (추후) SQLite |
| 데이터 소스 | Leaguepedia API (Fandom) |
